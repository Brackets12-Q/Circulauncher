# Circulauncher

I thought 
> Why must the launchers be rectangular?

So.. <br>
**Here comes Circulauncher** (Along with the bar I made for experimenting/custom aesthetic purposes) <br>
<br>
The idea is to create a flexible launcher/dock that can do anything, with the addition of a creative and cool-looking aesthetic. 
It is also meant to be easy to add onto, just like any pre-made bars would be.

Currently, the launcher supports a few operations:
- Launching an app
- Searching for an app
- Display date/time
- Audio Visualization
- Close Circulauncher

The bar supports these few operations: 
- Time
- Launch Circulauncher
- Switch Workspace
- Media Player
- Basic Bluetooth Controls
- Basic Volume Controls

Currently, I am working on scaling it. Now, it only works on 4K display screens. Not very well suited for 1K screens. 
Feel free to download and edit it yourself. If you have something that would seem nice to have everyone use, you can request / make a pull request 😄
